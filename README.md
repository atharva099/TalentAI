# TalentAI

TalentAI is an AI-powered Recruitment Management System designed to simplify and automate the hiring process.

## Tech Stack

### Backend
- Java 21
- Spring Boot
- Maven

### Frontend
- React
- Vite
- Tailwind CSS

### Database
- MySQL

## Features

- User Authentication
- Role-Based Access Control
- Candidate Management
- Job Management
- Resume Upload
- AI Resume Analysis
- Interview Scheduling
- Dashboard & Reports
